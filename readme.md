# ShopNest

A full-stack e-commerce application built with React, Node.js, Express, PostgreSQL, and Prisma.

## Features

- User registration and login
- JWT authentication with refresh tokens
- Product browsing and search
- Shopping cart
- Checkout and orders
- User account management
- Admin dashboard
- Product and category management
- Order management

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express
- TypeScript
- Prisma
- PostgreSQL
- JWT
- Zod

### Deployment
- Vercel
- Render
- Neon PostgreSQL
